# FinsROV 上位机控制台（Host_Console）

白底界面：左侧状态和操作按钮；右侧上方**实时曲线**，下方**事件记录聊天框**（下位机本次上电以来的全部停机、警告、信息、致命错误），
中间的分隔条可以上下拖动调整两部分大小。
配套 2026-10-12 修改后的下位机固件（带 `EventLog` 事件上报）。旧固件没有事件上报，只能发命令。

## 安装与运行

```bat
pip install -r requirements.txt        :: pyserial，pygame（可选，手柄）
python finsrov_console.py              :: 在界面里选串口后点"连接"
python finsrov_console.py --port COM11
python finsrov_console.py --mapping my_pad.json   :: 手柄编号和原来不一样时
```

* 串口格式固定 115200 / 8 数据位 / 偶校验 / 1 停止位（与下位机 USART6 一致）。VOFA、串口助手要先关掉。
* 没装 pygame 也能用（只用键盘和按钮）。
* 所有记录同时写到 `logs/finsrov_日期_时间.log`。

## 操作

| 手柄 | 键盘 | 作用 | 发出的命令 |
|---|---|---|---|
| Start | Enter | 解锁 / 停止（看下位机实际状态切换） | `ON` / `OFF` |
| Back | 空格 | 急停 | 连发 3 次 `OFF` |
| A / B | R / F | 上浮 / 下潜（按住 0.5 s 后连发） | `UP` / `DN` |
| 十字键 | W/S/A/D | 前 / 后 / 左 / 右 | `W` `S` `A` `D`，松开发 `Z` |
| X / Y | Q / E | 逆时针 / 顺时针 | `Q` `E` |
| LB | L | 锁定当前航向 / 关闭 | `ACL:ON`+`RPY:ON` / `RPY:OFF` |
| 摇杆 | — | 四路舵机（速率和范围与原程序相同） | `MOT:a,b,c,d` |
| 左/右摇杆按下 | — | 左侧 / 右侧舵机回中 | `MOT:...` |

左侧命令框可以发任意命令（如 `H:300`、`TES:1550,1550,...`）。按钮里的"水压标定"会先确认潜器在空气中。

**心跳**：程序每 100 ms 自动发 `HB`。新固件在推进器工作时连续约 0.67 s（100 个控制周期）收不到任何数据就停机（事件 102）。
所以**不要再用原来的 `usbCameraFullControl.py` 控制新固件**：它不发心跳，悬停时一松手就会被判掉线停机。

**上位机侧保护**：推进器在工作但 2 s 收不到状态行，上位机会主动发 `OFF` 并在聊天框里说明。关闭窗口或点"断开"也会先发 `OFF`。

## 实时曲线

* 左上角「曲线 ▾」勾选要显示的量，也可以一键切换常用组合：横滚/俯仰调参、偏航调参、深度调参、推进器 PWM。
* 每种单位一个小图（姿态角 °、角速度 °/s、深度 mbar、控制量 us、推进器 PWM us），不会把不同单位叠在一根轴上。
* 颜色按轴固定：横滚蓝、俯仰橙、偏航青、深度黄；**实线是实际值，同色虚线是目标值**（目标角速度 = 外环 PID 输出，目标偏航、目标深度）。
* 方向统一为 FRD：抬头、右倾、顺时针为正。角速度和目标角速度都换算成同一方向，可以直接比较内环跟踪得好不好。
* 鼠标移到图上显示十字线和该时刻各曲线数值；「暂停」冻结画面（数据照收），「时长」选 10/30/60/120 s。
* 姿态/角速度/深度/控制量来自下位机约 30 Hz 的 `$PL` 行，推进器 PWM 来自 10 Hz 的状态行。时间轴是板上时间。

## 事件记录怎么看

* 左侧灰/橙/红气泡是下位机事件：`#序号  板上 分:秒.毫秒  电脑时间`，下面一行是编号和名称，再下一行是参数解释。
  * 灰 `·` 信息（3xx）  橙 `▲` 警告（2xx，不停机）  红 `●` 停机（1xx，需重新 ON）  深红 `■` 致命（9xx，单片机已停住，要复位）
* 右侧蓝色气泡是上位机自己的动作（发了什么、串口断开……），时间显示"≈板上"估算时间，按这个时间插进同一条时间线。
* **先后顺序以下位机序号和板上时间为准**。串口丢了行，程序会自动发 `EVQ:<序号>` 让下位机补发，补回来的旧事件插回原位；
  下位机只保留最近 128 条，更早的若没收到会标"已被覆盖"。连上串口时会先请求从第 1 条补发，所以中途连上也能看到上电以来的全部。
* 下位机重启（复位、欠压……）会另起一段，分隔线上写着复位原因。致命错误会在顶部出现深红横幅。
* 顶部复选框可按级别过滤；"导出"保存为文本。

## 编号表

与下位机 `Lower_Level_Controller/userCode/devices/Inc/EventLog.h` 一一对应，说明文字见 `fins_codes.py`。
`python test_protocol.py` 会自动核对两边编号是否一致。

| 编号 | 级别 | 含义 |
|---|---|---|
| 101 | 停机 | 收到 OFF |
| 102 | 停机 | 心跳丢失：推进器工作时连续 100 周期没收到上位机数据 |
| 103 | 停机 | 垂直控制量连续 100 周期 NaN |
| 104 | 停机 | 偏航控制量连续 100 周期 NaN |
| 105 | 停机 | 推进器 PCA9685 连续 100 周期写失败（I2C 不通时中位也写不进，**请断电**） |
| 106 | 停机 | TCA9548A 连续 100 周期选通失败（同上） |
| 201–216 | 警告 | 水压/磁力计读失败沿用旧值、I2C 写失败首次、NaN 首次、串口错误、命令溢出、未知命令、HAL 初始化错误、BMI088/IST8310/SPI 初始化失败、舵机写失败等 |
| 301–310 | 信息 | 上电（含复位原因）、ON、TES、ESKF 就绪、偏航闭环开关、锁定航向、水压标定 |
| 901–908 | 致命 | HardFault / MemManage / BusFault / UsageFault / 未处理中断 / FreeRTOS 断言 / 栈溢出 / 调度器启动失败 |

## 协议（给以后改程序的人）

下位机 → 上位机（每行带 NMEA 式异或校验，校验错的行直接丢弃）：

```
$EV,<序号>,<板上ms>,<编号>,<参数>,<文本>*HH
$ST,<板上ms>,<最新序号>,<模式>,<最近停机编号>,<静默周期>,<目标深度×10>,<深度×10>,
    <横滚×100>,<俯仰×100>,<偏航×100>,<1=ESKF/0=IMU>,<运动状态>,<PWM0..7>,<水压有效位>*HH   约 10 Hz
$FT,<板上ms>,<序号>,<编号>*HH            致命后约每 0.5 s 重复，同时重发最近 16 条事件
$PL,<板上ms>,<横滚,俯仰,偏航,目标偏航 ×100 °>,<横滚/俯仰/偏航角速度 ×100 °/s>,<三个目标角速度 ×100 °/s>,
    <深度,目标深度 ×10 mbar>,<深度/横滚/俯仰/偏航控制量 ×10 us>*HH      约 30 Hz，画图用
```

上位机 → 下位机：命令以换行结尾；`HB` 心跳；`EVQ:<序号>` 补发。

## 文件

| 文件 | 内容 |
|---|---|
| `finsrov_console.py` | 界面和主循环 |
| `fins_protocol.py` | 解析、校验、排序去重、补发、重启识别（不碰串口和界面） |
| `fins_codes.py` | 编号表和参数解释 |
| `fins_link.py` | 串口收发线程、100 ms 心跳线程、断线每秒重连 |
| `fins_gamepad.py` | 手柄；启动时静止读数不为 0 的轴（扳机）自动屏蔽，防止舵机一开机跑到底 |
| `fins_chart.py` | 实时曲线（纯 tkinter，不需要 matplotlib） |
| `test_protocol.py` | 测试 |
